# Portfolio · Yoan Rousselot

Portfolio (français) : accueil et pages détaillées.

- `index.html` : page d'accueil
- `experiences/`, `projects/`, `education/` : pages détaillées
- `content.py` : tous les textes
- `build.py` : génère les pages (`python build.py`)
- `assets/style.css`, `assets/main.js` : style et animations

Site statique : aucun build nécessaire pour l'hébergement, le dossier racine est publié tel quel.
